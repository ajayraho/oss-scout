OSS Scout

Search GitHub for open-source issues worth picking up — filtered by language, recency, and ranked by how contested they already are.

Open OSS Scout → No signup required · Bring your own GitHub token

Smart filtering

Filter by programming language, star count, repo activity, issue age, and label — good first issue, help wanted, or any custom tag the project uses.

Competition scores

Each issue gets a LOW / MEDIUM / HIGH badge based on comment count, assignee presence, and linked pull requests — so you know where you actually have a shot before clicking through.

Direct issue search

Queries GitHub's issue search API directly instead of crawling repos one by one. Results come back fast and reflect real-time state on GitHub.

Multi-language

Search across Python, JavaScript, Go, Rust, and more in a single run. Results are deduplicated and ranked together so the best issues surface regardless of language.

How it works

From filters to a ranked list in seconds

01

Set your filters

Pick languages, star range, issue labels, max comments, and how recent the issue should be.

02

OSS Scout searches GitHub

Queries the GitHub Search API per language, verifies each repo against your filters, and scores every issue it finds.

03

Pick an issue and contribute

Results are grouped by repo with competition badges. Click any issue title to open it directly on GitHub.

04

Export or bookmark

Download results as CSV or star repos to a bookmark panel so you can come back later.
